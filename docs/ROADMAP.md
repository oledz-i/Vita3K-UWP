# Roadmap

No release dates or game-performance guarantees are assigned. Feature/UI decisions will be refined with the maintainer before substantial app development.

| Milestone | Exit criterion | State |
| --- | --- | --- |
| 0 — Repository and CI | Documented project, reproducible development APPX workflow | Foundation added; check Actions for current build result |
| 1 — Hardware foundation | Series S installation, activation and lifecycle report; resource/capability logging | Pending hardware validation |
| 2 — Core feasibility | Pinned upstream integration plan; dependency and JIT/memory probes pass | Research started; core not integrated |
| 3 — D3D12 backend | Correct Vita rendering through native D3D12 with homebrew evidence | Planned |
| 4 — Emulator experience | Agreed UI, game library, storage, controls, touch, audio and saves | Requirements pending |
| 5 — Compatibility | Reproducible per-title results and regression tracking | Blocked on core/backend |
| Parallel — Vulkan / OpenGL | Documented supported host paths; Xbox translation feasibility measured | Research only |
| Release readiness | Stable signing identity, source/license distribution, tested upgrades | Pending |
