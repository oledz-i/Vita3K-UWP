> **This is an alpha.** It runs real games, but expect bugs, crashes and games that don't work yet. Please read the known issues before you start.

This is the first public build of Vita3K for Xbox: the Vita3K PS Vita emulator running on Xbox Series X|S in Developer Mode, with a frontend made for a controller and a TV.

## What you need

- An **Xbox Series X or Series S in [Developer Mode](https://learn.microsoft.com/en-us/windows/uwp/xbox-apps/devkit-activation)**. Xbox One consoles aren't supported.
- **Your own PS Vita firmware.** The system firmware is required; the preinstalled package and the fonts are recommended. This project doesn't include firmware or say where to get it.
- **Your own games**: `.vpk`, `.zip`, `.pkg` with its license, or an extracted game folder.
- A USB drive (exFAT or NTFS) is strongly recommended for games and for Vita3K's data. Installed games get big.

## Installing

1. Download the files below: the Vita3K `.appx` and its x64 dependency package.
2. Open the Xbox Device Portal from a PC on the same network (`https://<your-xbox-ip>:11443`), choose **Add**, pick the Vita3K `.appx`, and add the dependency when it asks.
3. In Dev Home, highlight Vita3K, press **Menu → View details**, and set **App type** to **Game**. As an App the console gives it too little memory and closes it without warning.
4. Start it. The Home screen walks you through three steps: where Vita3K keeps its data, installing the firmware, and choosing your games folder.

The full guide is in [docs/INSTALL.md](https://github.com/oledz-i/Vita3K-UWP/blob/main/docs/INSTALL.md).

## What's in this build

### Emulation
- The full Vita3K core, with the ARM CPU recompiled to x86 by Dynarmic.
- **Two renderers**: Vulkan (through Mesa's Dozen) and OpenGL (through Mesa), both running on the console's Direct3D 12. Some games are happier on one than the other, so you can switch in Settings.
- Frame pacing locked to your TV's refresh, frames delivered in order, and shaders compiled in the background, so new effects don't freeze the game.
- A faster CPU path: atomics run natively, NEON math skips needless floating-point mode switches, and the core is built for the Xbox's Zen 2 processor.
- Buffered audio that doesn't crackle when a frame runs long.
- Saves, trophies and the system dialogs (save screens, messages, the on-screen keyboard).
- Updates and DLC install from a folder you choose. An update can even go in before you've played its game.
- Quitting one game and starting another restarts the app cleanly between them.

### Games
Tested and playing: **Terraria** (a steady 60 fps), **Undertale**, **Danganronpa: Trigger Happy Havoc** and **Ultra Despair Girls**.
Running with rough edges: **Gravity Rush**, **Persona 4 Golden** and **Minecraft: PS Vita Edition** (Vulkan only).
More detail per game is on the [compatibility page](https://github.com/oledz-i/Vita3K-UWP/blob/main/docs/COMPATIBILITY.md).

Some games come with their fixes built in. Danganronpa, for example, always starts on OpenGL with surface sync on, because that's what gets it past the interaction bug it has in Vita3K.

### The frontend
- **Two home screens**: a cinematic one with big artwork, or a **PS3-style XMB** in eleven colours (Classic Blue by default; Monthly follows the month like the PS3 did).
- **SteamGridDB artwork**: add your own API key for covers and wide backdrops, with a picker to choose different ones. Games without a backdrop get one from a screenshot taken while you play.
- Five themes, four original menu tracks, interface sounds, or your own music.
- A touch cursor for games that need the touch screen or the rear touchpad.
- **24 Vita3K settings**: resolution, filtering, shader compiling, the CPU, system language, PSTV mode and more.
- Firmware installs in one go: pick all the `.PUP` files under any names and the app sorts out which is which.
- A diagnostics report in Settings, and a performance line in the log every minute.

### Controls
- **View + Menu** together: quit the game back to the library.
- **R3** (click the right stick): turn the touch cursor on or off. With it on, the right stick moves it, **RT** touches the screen, and **LT + RT** touches the rear touchpad.
- In the XMB: left/right changes category, up/down chooses, **A** opens, **Y** opens a game's page, **B** goes back.

## Known issues

- **Minecraft** only runs on Vulkan (it crashes on OpenGL) and some of its text is garbled. In the world it now reaches around 24 fps, which is playable but not smooth. **Opening the creative inventory drops it to roughly 8 fps** until you close it.
- **Uncharted: Golden Abyss** doesn't get past its splash screen on Vulkan. The app keeps responding and the quick menu still works, but the game never goes on from there. A fix is planned for the next patch.
- The first time a game uses a new shader, the console can take a second or two to compile it. Until then, whatever that shader draws is missing. The game doesn't freeze.
- Some games work on only one of the two renderers. If something looks wrong, try the other.
- This build is signed with its own certificate. Builds signed differently may need the old one uninstalled first, and **uninstalling deletes data kept on internal storage**. Data on a USB drive stays, so keep it there.

## Reporting problems

Open an issue on this repository with:
- the game and its title ID (for example PCSE00491),
- the renderer you used,
- what happened and when,
- `vita3k-runtime.log` from Device Portal → File Explorer → LocalAppData → Vita3KUWP_… → LocalState.

Please don't report this port's problems to the Vita3K team. They're ours, not theirs.
